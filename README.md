# Phidel Ochieng Portfolio

Personal portfolio for Phidel Emmanuel Ochieng. Vanilla HTML, CSS, and JavaScript. No frameworks.

**Live site:** [phidelemmanuelochieng.vercel.app](https://phidelemmanuelochieng.vercel.app/)

## Design

- Light-first craft look with cool stone surfaces and a forest teal accent
- Typography: Bricolage Grotesque (display) and Figtree (body)
- Sharp corners, border-led layout, no drop shadows or glass effects
- Full-bleed portrait hero with brand-first copy
- Stacked case studies and list layouts instead of card grids
- Optional dark theme, reduced-motion support

## Sections

- Hero, selected work, about, experience, journey, certifications, services, GitHub, contact
- Resume page, terms, and privacy pages
- Contact form via FormSubmit with honeypot spam protection

## SEO and security

- Meta title, description, canonical, Open Graph, Twitter cards, JSON-LD
- `robots.txt`, `sitemap.xml`, descriptive image `alt` text
- CSP, HSTS, frame denial, nosniff, referrer policy via `vercel.json`
- XSS-safe GitHub API rendering with URL sanitization
- No API keys in client code; GitHub public API only

## Search Console

Replace `REPLACE_WITH_SEARCH_CONSOLE_TOKEN` in `index.html` with your Google Search Console verification token after you claim the Vercel property.

## Local preview

```bash
python3 -m http.server 8080
```

Open `http://127.0.0.1:8080/`.
